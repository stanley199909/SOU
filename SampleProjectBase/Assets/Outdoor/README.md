# Outdoor stage and lighting

A small courtyard shared by SceneForge and StageEditor. Defaults are in Assets/outdoor_stage.txt; saved stage_layout.txt transforms override them. Use Shift+Left/Right to enter the editor and View outdoor yard to inspect the exterior. Save layout now persists object transforms. Cottage material/light controls are shared by both scenes.

The sky and direct light use the same sun direction. A cached 2048-square shadow map covers 48 metres around the cottage, including static workshop props and exterior objects. Glass is excluded from shadow casting so sunlight can enter the actual window opening. This is static geometry sunlight, not volumetric lighting; moving weapons and point-fire shadows are not included. The shadow is refreshed when scene transforms or sun direction change.

Model loading reconstructs missing/invalid normals from triangle geometry. Valid authored normals remain unchanged. Shader texture storage uses reflected register indices, including sparse bindings. Indoor fill is restored to 4.0 and exterior fill defaults to 2.4.

Assets: procedural exterior meshes generated by Tools/build_outdoor.py. Added textures are CC0 Poly Haven brown_mud_02 and grass_path_2:
https://polyhaven.com/a/brown_mud_02
https://polyhaven.com/a/grass_path_2
Checksums and download references: Tools/outdoor_texture_sources.json.

Verification: Tools/build_outdoor_probe.cmd builds a noninteractive D3D11 WARP test using production model/texture/shader code. Run Tools/outdoor_probe.exe from the project directory with the project directory on PATH. PROBE_INTERIOR=1 selects the indoor camera. It writes Tools/outdoor_probe.png; it does not capture the game window. Final reference renders are Tools/interior_verified.png and Tools/outdoor_verified.png. Its CPU tone map approximates the display and is not the full game postprocess. Actual game FPS and final appearance still need in-game verification.

Restart the game after building: an already running executable cannot pick up C++ changes. Exterior art is an initial functional version, with further vegetation/ground polish still possible.
