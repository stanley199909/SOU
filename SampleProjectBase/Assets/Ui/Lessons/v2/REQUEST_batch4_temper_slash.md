# 第四批请求：回火（temper）与试斩（slash）

两课都沿用 `STYLE.md` 的第二版风格与 `ANIMATION_FORMAT.md` 的逐帧协议，不改格式。

## 共通规则（与前三批相同）

- PNG：512×512 RGBA，真透明背景。生成时用不透明深炭灰 `#20242A` 底，之后用程序去底（与前几批同一流程）。
- 前臂、手、工具、环境、箭头：白色实心剪影。铁（刀身）：白色粗线空心轮廓。
- 不画完整人物或头，不加文字、数字、纹理或渐变。缩小到 90×90 时要能看懂。
- 每课交付：base / pose PNG、`lesson_<id>_animation.json`（`frames` 内含 base、pose、duration_seconds、dx、dy、tilt、pivot）、`preview_<id>_frames.gif`。
- `playback: step`（逐格跳换、停留，不补间）。base 与 pose 画在同一个 512 画布的同一位置，不要分别居中。
- 交付时写清楚各帧的停留秒数，以及 dx/dy/tilt 是否为 0。

## 1. 回火 `lesson_temper`（焼き戻し）

**要教的操作**：刀平放在炉的炭火上方，用手（火钳）左右来回移动，让刀均匀受热；表面的回火色从**刀背往刃口**扩散，刃口变成“麦色”时，用火钳把刀夹起来拿走。

**视角**：俯视（从正上方看刀的平面）。刀横放，刀尖朝左、刀根朝右，和 `grind_slide` 一致。

**环境（base）**：刀下方是一排炭块，用白色实心的圆角小块表示，排成横向的一长条；炭块上方画 2～3 道短的波浪线，代表热气（实心白、粗线）。不要画完整的炉子。

**颜色的表现方式**：图是单色的，不能直接画颜色。“回火色”改用**刀身里面的实心白色带**来表示：
- 色带从刀背（中线）开始，向两侧的刃口变宽。
- 实心白色带 = 已经变色的部分，空心 = 还没变色的部分。
- 刃口边缘留一点空心窄边，直到最后一格才填满。

**帧（4 格，单手 + 火钳夹住刀根）**：

| 格 | base | pose | 停留 | dx | 内容 |
|---|---|---|---|---|---|
| 1 | base | pose1 | 0.6 秒 | −50 | 刀在炭上**偏左**；刀身全空心（还没变色）。 |
| 2 | base | pose2 | 0.6 秒 | +50 | 刀**偏右**；刀背出现窄的实心色带。 |
| 3 | base | pose3 | 0.6 秒 | −50 | 刀回到**偏左**；色带变宽，接近刃口。 |
| 4 | base | pose4 | 1.4 秒 | 0 | 色带碰到刃口；火钳把刀**往上提起离开炭火**。 |

- 底图只有一张 base（炭火和热气），四格都不变。
- 刀、色带、火钳和手都画在 pose 层，因为色带要跟着刀一起移动。pose1～pose3 里的刀、手、火钳形状和位置完全一样，只有刀身里的色带宽度不同；左右移动用 `dx` 表示，跟 `grind_slide` 一样。
- pose4 = 色带填满到刃口，刀、手、火钳整体往上移约 60px（直接画在 pose4 里，dx/dy 为 0），刀不要整个离开画面。

## 2. 试斩 `lesson_slash`（試し切り）

**要教的操作**：长按举剑，剑竖在右肩上方（长剑的“屋顶式”架势，Vom Tag），屏息等瞄准稳定；放开，往左下方斜劈（Zornhau），把稻草人的躯干斩断。

**视角**：第一人称，从持剑者的视线往前看。画面下方是双手握住剑柄；前方是稻草人。

**环境（base）**：画面中央偏左是稻草人。木柱是实心白，躯干是实心白的圆柱或袋子形状，头是实心的圆，比例要简单，不画脸。稻草人的位置在三格里都不变。

**剑**：剑刃用空心粗线轮廓（铁），护手和剑柄用实心白，双手用实心白的拳头。

**帧（3 格）**：

| 格 | base | pose | 停留 | 内容 |
|---|---|---|---|---|
| 1 | base | pose1 | 1.2 秒 | **举剑**：剑竖在画面右侧，剑尖朝上，略向后倾。双手在画面右下方，握住剑柄。稻草人完整。 |
| 2 | base | pose2 | 0.12 秒 | **挥下的瞬间**：剑斜在画面中央，从右上往左下。剑后面拖 2～3 道弧形的粗白线，代表挥动的轨迹。 |
| 3 | base2 | pose3 | 1.2 秒 | **劈完**：剑在画面左下方，剑尖朝左下。稻草人的躯干沿着**右上到左下的斜线**断开，上半截往左下方滑开约 20px。 |

- base2 = 被斩断的稻草人：断口是一条明显的斜缝，宽约 8px，空出深色背景。
- 斩断方向要跟挥剑方向一致（右上 → 左下）。
- 不要加速度线以外的特效，不要血或碎片。

## 自检

- 90×90 深色背景下：回火能看出“刀在炭上左右移动 → 刀身里的白色带越来越宽 → 刀被夹起”；试斩能看出“举起 → 斜劈 → 断开”。
- 每帧使用 JSON 指定的 base（回火四格都是同一张 base；试斩第 3 格换成 base2）。回火的 dx 要在运行时套用，不要再画进 PNG 里。
- 不要修改游戏代码。交付后由 Claude 把两课登记到游戏里（`Tutorial.cpp` 的 `LESSON_PICTURES`）。
