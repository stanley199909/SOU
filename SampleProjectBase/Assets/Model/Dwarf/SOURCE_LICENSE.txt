README & LICENSE — Dwarf Base Models

Overview
This package contains two stylized dwarf base models (male & female), including a Blender project file and exported FBX versions. The models are designed for use in games, prototypes, animation, and other creative projects. A basic Mixamo walk animation is included inside the Blender file as part of the rigged character.

Included Files:

DwarfMaleFemale.blend
	- Male dwarf
	- Female dwarf
	- Mixamo Rigged versions with Walk animation

DwarfMaleBody.fbx
	- No rig, no animation

DwarfFemaleBody.fbx
	- No rig, no animation

DwarfMaleTPose.fbx
	- Mixamo Rigged T-Pose

DwarfFemaleTPose.fbx
	- Mixamo Rigged T-Pose
