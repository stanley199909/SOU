# 追加请求：给刀身做第三个状态 stage_1（锻造完成、尚未研磨）

现在刀身有两个状态：`stage_0`（粗坯铁条）和 `stage_final`（研磨好的成品）。请在中间加一个状态 **`stage_1`**：**锤打成形了，但还没研磨**。刃口是真实的网格，不是贴图或着色器做的效果。

游戏的流程：锻造 = `stage_0 → stage_1`，研磨 = `stage_1 → stage_final`。

## 不能改变的条件
- 三个状态**顶点数、顶点顺序、面的索引、UV 必须完全相同**（游戏逐顶点插值）。所以 `stage_1` 只能**移动顶点**，不能增删顶点或面。
- 全部是封闭实体：开放边 = 0、非流形边 = 0。
- `make_stages.py` 不要修改。

## 步骤（在 `Assets/Model/weapon/sword.blend` 里）
1. **先备份**：把 `Assets/Model/weapon/` 现有的 `stage_0.obj/.mtl`、`stage_final.obj/.mtl`、`sword.blend` 复制到 `Assets/Model/weapon/old_two_stage/`。
2. **加密长度方向**：`Medieval_Sword_Blade` 现在每 1.5 cm 一圈。缺口需要更细的顶点，请用 `bmesh.ops.bisect_plane` 改成**沿长度每 0.5 cm 一圈**，外形不变、UV 保留。总顶点数控制在 **7000 以内**；如果超过，就减少**刀身中央**宽度方向的切分，保留靠近两侧刃口的切分。
3. 执行 `make_stages.py`，重新生成 `stage_0.obj` 和 `stage_final.obj`。
4. **做 `stage_1`**：复制 `Medieval_Sword_Blade`（`mesh` 也要复制一份），命名为 `stage_1`，只移动顶点：
   - **宽度**：两侧的刃口向内缩，形成**不规则的锯齿缺口**。深度约为刀身半宽的 **5% ~ 25%**（约 1.2 ~ 6 mm），左右两侧的形状**不要相同**，起伏要像锤打留下的自然崩口，不要规则的波浪。
   - **缺口要贯穿厚度**：同一个长度、同一个宽度位置的正面和背面顶点要一起移动，使缺口是实心的切面，不能只动一面。靠近刃口的顶点移动最多，往刀身中央约 1/3 处逐渐减为 0。
   - **厚度**：还没研磨，所以刃口是钝的：把刃口的厚度加到约 **2 mm**（成品几乎是尖的），刀身其他部分的厚度为成品的 **1.3 倍**。
   - **轮廓**：长度与成品相同，刀尖位置不变。
   - 用脚本（固定随机种子）生成，方便重做。
5. 重新计算 `stage_1` 的法线，导出 `Assets/Model/weapon/stage_1.obj`（只选这一个对象；设置与 `make_stages.py` 相同：UV、法线、Forward -Z、Up Y）。
6. 存档 `sword.blend`。
